# 센터 PC 실행 적합성 검토

검토일: 2026년 11월 6일

## 판단

Intel i3-13100, RAM 8GB, Samsung PM9B1 512GB, 외장 GPU가 없는 PC는 계획한 20종 그림 맞히기에 적합하다. 작은 CNN 하나로 흑백 그림을 분류하는 작업과 2D 터치 화면은 CPU 실행을 기준으로 개발할 수 있다. 하드웨어 증설은 현재 요구사항의 전제 조건이 아니다. 최종 안정성 판정은 완성 모델을 현장 PC에서 측정한 뒤 내린다.

## 현재 구현 상태

현재 저장소의 ai-drawing-kiosk는 고양이 그림을 이어 그리는 이전 시제품이다. model-worker.js에서 CPU를 명시하고 Web Worker에서 SketchRNN을 실행한다. 모델 파일은 2,997,378바이트다. 이는 별도 GPU를 요구하지 않는 구현이지만, 현장 PC의 지연 시간과 연속 운영 결과는 아직 측정하지 않았다.

현재 저장소에는 퀵드로우용 20종 분류 모델과 완성된 게임 구현이 없다. 기존 생성 모델의 테스트 결과나 파일 크기로 새 분류 모델의 속도와 인식 정확도를 검증했다고 간주하지 않는다.

## 반영한 개발 기준

PRD 0.2에 센터 PC를 기준 장비로 명시했다. CPU 전용 단일 스레드 WASM, 추론 Worker 하나, 모델 한 번 로딩, 최신 입력만 처리하는 대기열, 250ms 기본 인식 주기와 500ms 부하 조절 주기를 적용한다. 그림의 선은 추론과 독립적으로 즉시 화면에 그린다.

앱 전체 프로세스의 물리 메모리는 600MB 이하를 목표로 하고 최대 1GB 이하를 검증 기준으로 삼는다. Canvas 내부 해상도와 회차 그림 보관량을 제한하고, 완료된 회차의 그림과 추론 자원을 정리한다. 20개 키워드와 무작위 출제 요구사항은 유지한다.

## 현장 합격 절차

1. 센터 PC의 운영체제와 상주 프로그램을 기록하고 사용 가능한 메모리를 확인한다.
2. 외부 네트워크를 차단하고 앱을 새로 실행한 뒤 모델 준비와 게임 완료를 확인한다.
3. 실제 터치 드로잉에서 추론 P95 150ms, 기본 후보 표시 P95 400ms, 부하 조절 모드 P95 750ms 목표를 확인한다.
4. 앱 전체 프로세스의 물리 메모리 합계가 최대 1GB 이하인지 측정한다.
5. 8시간 운영과 100회 반복 체험으로 종료, 멈춤, 메모리 누적, 이전 회차 그림 잔류를 검사한다.
6. 실제 초등학생의 그림으로 정확도를 검증한다. 실행 속도와 인식 정확도는 각각 합격해야 한다.

수치들은 개발 및 인수 목표이며 실제 장비에서 측정한 결과가 아니다.
